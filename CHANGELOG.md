## 0.4.1

- Fixed Windows update-package creation failing on Electron files with invalid ZIP timestamps.
- Packaging now stops cleanly if update compression fails instead of throwing a misleading rename error.

# Changelog

## 0.4.0

- Added bundled offline fonts: Inter, Lato, Noto Serif, Comfortaa.
- Added font-family selection for text layers.
- Added text alignment control and matching exported alignment.
- Removed Google Fonts runtime dependency.
- Preserved the v0.3.x user-data path for autosave compatibility.
- Added a one-time Windows installer generated by `npm run package:win`.
- Added `.frameupdate` packages and **Help > Install Update Package...**.
- Updates replace application files only; projects/autosaves remain separate.
- Fixed duplicated background-swatch declaration left in v0.3.1 source.
